# Video Grabber — downloads

This repository only hosts finished downloads of **Video Grabber**, a free browser extension that
downloads videos and music from web pages (no paywall). The source code is kept elsewhere.

## Install

1. Open **[Releases](../../releases)** and download the newest `video-grabber-X.Y.Z.zip`.
2. Unzip it and open **`START HERE.html`** inside: it walks you through every step (English and German).

Short version: `chrome://extensions` → turn on **Developer mode** → **Load unpacked** → pick the unzipped
`video-grabber` folder. Works in Chrome, Edge and Brave on Windows, macOS and Linux.

## Updates

Turn on automatic updates once in the extension's settings (gear icon → **Updates**). Installed copies
then check `latest.json` in this repository and update themselves. Every update is signed; the extension's
helper verifies the signature before installing anything.

## Fine print

Video Grabber never downloads DRM-protected streams. Only download what you have the right to keep.
